# Use a fixed isometric viewing direction

The game will use a fixed isometric viewing direction with panning and zooming, and larger buildings will initially support two authored orientations. The user accepted this direction to focus the presentation and art workflow on a consistent set of views across buildings, characters, and coastline while retaining placement flexibility. World-view rotation is outside the initial camera scope; the exact two building facings will be specified in the art guide.
