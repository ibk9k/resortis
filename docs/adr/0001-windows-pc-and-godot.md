# Target Windows PC and use Godot

The game will initially target Windows PC with mouse-and-keyboard input, using Godot 4 with typed GDScript as the selected engine direction. This focuses design and validation on a desktop management experience and uses the engine's existing 2D, isometric tile, animation, and UI tooling; the browser-focused Phaser/TypeScript alternative was considered before the platform was selected. Steam remains a possible distribution channel, and the exact stable Godot release will be pinned during setup. This decision establishes the platform and engine direction without committing the feature scope or release schedule.
