# Start with fully furnished accommodation units

For the initial version, players will place complete furnished accommodation units, each providing basic bathroom and shower access, with decoration focused mainly on the surrounding resort. This selects the complete-unit model over customizable shells or freeform rooms, concentrating the first implementation on resort layout and management while reducing the initial interior-editing and asset requirements. The user remains interested in future customization; consider that extension when designing building definitions and saves, while leaving the editor, exact customization features, and schedule for later decisions.
